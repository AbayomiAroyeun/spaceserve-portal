This web infrastructure is engineered for rapid asset delivery and strict user privacy:

## 🚀 How to Run and Preview Locally

To clone the portal repository and spin up a local developer sandbox:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd spaceserve-portal
   ```
3. **Open the project:**
   * Open `index.html` directly in your browser of choice, or
   * Use the **VS Code Live Server** extension to launch a local development hosting pool at `http://127.0.0.1:5500`.
